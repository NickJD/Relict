# Relict
Relict is used to identify candidate relict lineages — taxa detected exclusively or predominantly within a given dataset with no close representatives in existing reference collections

"Has anyone found and characterised this organism before, or does it only exist in our dataset right now?"

The relict framing answers this beautifully across multiple scenarios:
- Scenario A — Truly novel sequence
Nobody has sequenced this lineage before. It sits alone on a long branch. In Relict's language: this is a relict lineage, surviving and undetected, only now surfacing in your dataset. The name implies you are the first to shine a light on it.
- Scenario B — Underrepresented lineage
A few sequences exist in SILVA/GG2 or Hungate but the lineage is sparse and poorly characterised. Relict flags it as worth keeping — it represents something real but neglected. The "only found here" implication holds: this study is one of very few places this organism has been detected.
- Scenario C — Known, well-represented sequence
Relict tells you this one isn't a relict at all — it's cosmopolitan, well-sampled, not worth prioritising for further work.
